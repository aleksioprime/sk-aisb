# Модель распознавания

Всё, что нужно, чтобы получить новый `app/best.pt`: сбор снимков, обучение и
экспорт. Выполняется на компьютере (обучение - на ПК с GPU или в Google Colab).

| Раздел | Что там |
| --- | --- |
| [collect/](collect/README.md) | сбор снимков с камеры ПК или Raspberry Pi |
| [training/](training/README.md) | датасет (не в git), ноутбуки обучения YOLOv8, зависимости |
| [export/](export/README.md) | экспорт в NCNN для слабых плат |

Текущая модель различает `hand`, `organic`, `paper`, `plastic`; `hand`
приложение игнорирует.

## Порядок обновления модели

1. **Снимки.** Лучший источник - сбор на самом устройстве во время работы
   (настройки → «Датасет»). UMKA сохраняет кадр каждого решения с рамкой
   модели в формате YOLO, а ответы посетителей сортируют кадры:
   «Да» - `confirmed` (разметка верна), «Нет» - `rejected` (модель ошиблась,
   переразметить - самые ценные кадры), без ответа - `unverified`; ложные
   срабатывания на пустой площадке - `background`. Кнопка «Скачать архив»
   даёт ZIP с `data.yaml`, который импортируется в Roboflow.

   Дополнительно удобно снимать камерой самого устройства в реальном
   освещении. Готовые снимки пустой площадки уже есть на устройстве - их
   собирает вкладка «Пустая площадка» в настройках:

   ```bash
   scp 'orangepi@192.168.10.100:app/data/empty_platform/*.png' model/collect/snapshots/
   ```

   Пустая площадка с бликами - главный источник ложных «пластиков». Добавьте
   такие снимки в датасет **без разметки** (фоновые изображения): так модель
   учится не находить на них предметы.
2. **Разметка и датасет** - в Roboflow, экспорт в формате YOLOv8 в
   `model/training/dataset/` (см. [training/README.md](training/README.md)).
3. **Обучение** - ноутбук `yolo_train_pc.ipynb` или `yolo_train_colab.ipynb`.
   Размер входа держите `416`: так модель запускает приложение
   (`image_size` в `app/sorter/config.py`).
4. **Установка на устройство.** Скопируйте веса в `app/best.pt` и обновите
   код на плате:

   ```bash
   deploy/install.sh orangepi@192.168.10.100 --code-only
   ```

   Если изменились имена классов, проверьте `class_aliases`,
   `ignored_classes` и `class_to_section` в `app/sorter/config.py`.
